# modelo-abandono-bancario
Modelo de Predicción de Abandono de Usuarios Bancarios 
Este repositorio contiene el desarrollo de una solución analítica integral para abordar el problema de la deserción de clientes en una entidad financiera. El proyecto abarca desde el análisis exploratorio hasta la implementación, optimización e inferencia de modelos de Machine Learning aplicados al campo del análisis de crédito y riesgo.
